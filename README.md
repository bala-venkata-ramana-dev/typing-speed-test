# Typing Speed Test

## Project Overview
Typing Speed Test is a web-based application that helps users measure their typing speed and accuracy.

## Technologies Used
- HTML5
- CSS3
- JavaScript

## Features
- User-friendly interface
- Real-time typing experience
- Calculates typing speed (WPM)
- Measures typing accuracy
- Displays typing results

## How to Run
1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in your browser.

Developed this project to improve my frontend development skills and JavaScript knowledge.
